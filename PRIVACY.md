# Privacy Policy

Last updated: 2026-08-03

Rhythia Reimagined is an unofficial community browser extension for Rhythia.
It is maintained by Shurielx and is not affiliated with or endorsed by Capo
Games.

This policy describes the extension's own data handling. Rhythia and Capo Games
operate their own services and policies.

## What the extension reads

The extension reads information already shown on Rhythia pages, such as public
profile and score information, and the page state needed to improve the
interface. It does not use device location to determine a country.

The extension uses only the access needed for its local features, such as saving
settings and history, communicating with the active Rhythia page, and optionally
creating local backups. It does not read or store browser cookies. If a Rhythia
session token is needed, it is used only for the current official API request
and is not saved by the extension.

## Service dependency and account terms

Features that load Rhythia data depend on the availability, structure, and
access rules of Rhythia pages and official Rhythia services. Capo Games may
change, restrict, or discontinue those services, so the maintainer does not
guarantee uninterrupted availability or compatibility with future changes.

The extension is an unofficial community tool and does not change the terms
that apply to a Rhythia account. Users are responsible for deciding whether
their use complies with those terms. The maintainer does not control account
reviews, restrictions, suspensions, or other actions taken by Capo Games and is
not responsible for those decisions, except where applicable law provides
otherwise.

## Where data is stored

Settings, history, statistics, and other data needed for the extension's
features remain local in the user's browser. Temporary information is used only
for the relevant feature or browser session.

The extension does not send this data to the maintainer, GitHub, analytics
providers, advertisers, or data brokers. It does not sell or monetize user data.

## Local backup

Local backup is optional and disabled by default. If the user grants access to a
selected folder, the extension can save copies of selected local data there.
Backups are not uploaded, synchronized, or shared by the extension. Backup files
may contain personal information; users are responsible for choosing a suitable
location, protecting the files, and deleting them when they are no longer
needed.

## Retention and deletion

Users can manage and delete local data through the extension and can remove
local backup files themselves. Uninstalling the extension may not remove files
saved outside the browser's extension storage. These controls do not delete or
change records held by Rhythia or Capo Games.

## Network and reports

Features that load Rhythia data use Rhythia pages and its official services. The
extension does not automatically send data to GitHub, analytics, advertising,
or other unrelated external services.

Users may report issues or privacy questions through GitHub Issues or by email
at `shurieldev@gmail.com`. The extension does not create GitHub issues
automatically. Anything a user voluntarily includes in a public issue is
handled by GitHub under GitHub's policies; do not include sessions, cookies,
private messages, or unredacted backup files.

## Third-party services

Rhythia and Capo Games independently control their own server-side processing,
retention, terms, and privacy practices. Questions about a Rhythia account,
official server records, or official Rhythia services should be directed to the
official Rhythia support channels.

References:

- [Rhythia Terms and Privacy](https://github.com/Capo-Games/terms-privacy)

## Children's privacy

The extension is not directed to children. The maintainer does not knowingly
collect personal information through the extension. If you believe sensitive
information was submitted through GitHub or email, contact the maintainer so it
can be addressed.

## Changes

This policy may be updated when the extension's data handling changes. The
latest version is published in this repository.
