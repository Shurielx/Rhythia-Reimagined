# Security Policy

Please do not include authentication sessions, cookies, private messages,
local backup files, profile exports, or other sensitive data in a public issue.

For a suspected security problem, email `shurieldev@gmail.com` before opening
a public issue. Include a short description, affected version, reproduction
steps, and the minimum information needed to verify the report. GitHub does not
provide a general private direct-message channel between user profiles, so do
not rely on a GitHub profile for confidential reports.

The extension may write user-approved backups to a local folder. These files can
contain profile information and other private data. Do not upload them to
GitHub, attach them to an issue, or send them by email without removing
sensitive information first.

Local extension storage and backup files are not intended to be a secure vault.
Anyone with access to the browser profile or backup file may be able to read
them. If a local backup or restore reports an error, keep the file private and
report only the error message, extension version, and reproduction steps.

## External service and account risks

The extension depends on Rhythia pages and official Rhythia services. Capo Games
may change or discontinue those services, which can reduce or break extension
functionality. Users are responsible for following the terms that apply to
their Rhythia account; this project is not affiliated with or endorsed by Capo
Games.
