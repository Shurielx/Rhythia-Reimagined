# Security Policy

Please do not include authentication sessions, cookies, private messages, or
other sensitive data in a public issue.

For a suspected security problem, contact the maintainer privately through the
GitHub profile before opening a public issue. Include a short description,
affected version, reproduction steps, and the minimum information needed to
verify the report.

This public repository contains only the Streamslop data catalog and support
documentation. The extension source code and developer tooling remain in a
separate private repository.
