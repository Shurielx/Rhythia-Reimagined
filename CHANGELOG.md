# Changelog

All notable user-facing changes are documented in this file.

## 1.0.0 - 2026-08-06

- Official production release of Rhythia Reimagined.
- Official browser support for Google Chrome 116+ and current Opera.
- Enhanced Rhythia profile and score views, performance statistics, filters,
  progression and rank tracking, and profile comparison tools.
- Local history and storage management, with optional manual, automatic, and
  recovery backups in a user-selected folder.
- Community-maintained Streamslop catalog integration.

See [Installation](INSTALLATION.md) and [Data and Backups](DATA-AND-BACKUPS.md)
for usage information.
